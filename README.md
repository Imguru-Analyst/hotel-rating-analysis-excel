# KFC Sales Analysis Dashboard using Excel

## 📌 Project Overview

This project analyzes KFC sales data using Microsoft Excel to understand sales performance, branch performance, customer distribution, and monthly sales trends across different countries and years.

An interactive Excel dashboard was created to transform raw sales data into meaningful business insights using Pivot Tables, charts, and slicers.

## 🎯 Project Objectives

- Analyze monthly sales trends
- Compare sales performance across countries
- Analyze branch-wise sales
- Understand customer distribution by country
- Categorize branch performance
- Identify high and low sales periods
- Create an interactive sales dashboard

## 🔍 Key Insights

- February recorded the highest monthly sales at **107.5K**.
- December recorded the lowest monthly sales at **90.7K**.
- Canada recorded the highest country-wise sales at approximately **247.3K**.
- USA recorded the lowest country-wise sales at approximately **226.5K**.
- KFC_CA_Q2 recorded the highest visible branch sales at approximately **125K**.
- The **Good** branch-performance category had the highest count with **4,846** records.
- Canada had the highest customer count at approximately **6.2K**.
- Sales declined during July and August before recovering in September.
